description: Generate a plain-text task brief for Claude, Gemini, or Codex (weave prompt)
---
Run `node cli/weave.js prompt $ARGUMENTS` (or the Weave MCP `prompt` tool) and show the brief exactly as printed, as plain text. The first argument may be a target (`claude`, `gemini`, `codex`); with no task, the brief is built from `.weave/state.md`.
